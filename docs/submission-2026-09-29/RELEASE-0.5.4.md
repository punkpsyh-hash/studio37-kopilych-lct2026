# Обновление 0.5.4 · 29.09.2026

Актуальный файл для установки — [APK 0.5.4 arm64](https://github.com/punkpsyh-hash/studio37-kopilych-lct2026/releases/download/v0.5.4-lct2026/kopilych-0.5.4-arm64-release-20260929-f.apk), SHA-256 `1969D91D24BD99660808DF21AA804BE75152C776BEE836365B9C8BA32F229C75`, размер 261 348 683 байта. Пакет `ru.studio37.kopilych`, versionCode `4011`, minSdk 24, targetSdk 35, только `arm64-v8a`; подпись v2 и ZIP-целостность проверены. Размер APK конкурсом не ограничен.

В сборку добавлен **офлайн-классификатор вопросов о финансах** на базе дообученного ruBERT tiny2 в формате ONNX int8. Он выбирает ответ из 34 заранее проверенных карточек, а не сочиняет текст. Опасные темы обрабатываются правилами до запуска модели; неуверенный ответ предлагает уточнение или обратиться к взрослым. Помощник не меняет кошелёк, награды и сохранения, не обращается к сети и не сохраняет детские вопросы. Панель открывается кнопкой «?» поверх полноэкранной комнаты. При ошибке модели включается прежний справочник.

Токенизация совпала с 29/29 эталонных запросов. На Windows реальный int8-инференс с ONNX Runtime 1.17.1 прошёл проверку верхней метки (не менее 27 из 29) и вероятностей (допуск ±0,05). Android arm64 debug и release APK собраны с одной библиотекой `libonnxruntime.so` и моделью 5,6 МБ; fp32-модель и контрольные запросы не входят в APK. Пройдены целевые тесты политики, резервного ответа и адаптивной панели. **Инференс на физическом Android не проверен:** подключённого устройства в среде сборки нет.

Исправления камеры, HUD, кормления/мытья и пути к посуде из [обновления 0.5.3](RELEASE-0.5.3.md) сохранены. Установка, звук, видимость анимации под Flutter HUD и полный цикл посуды на физическом телефоне ещё требуют проверки. Презентация и PDF-руководство описывают базовую сборку 0.5.2; этот документ фиксирует изменения актуального APK.
