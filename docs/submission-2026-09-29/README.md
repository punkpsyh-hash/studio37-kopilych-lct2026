## Стек и состав репозитория

- `app/` — Flutter/Dart, Android-проект, экраны, тесты; SQLite через `sqflite` хранит локальные основной и отдельный демонстрационный профили.
- `app/assets/game3d/` — исходный код локальной полноэкранной 3D-сцены WebView/Three.js. Большие игровые модели, изображения и звук восстанавливаются из APK релиза скриптом `tools/restore_assets_from_apk.py`; они не входят в Git из-за объёма. Модель финансового помощника `app/assets/helper/model_int8.onnx` включена в репозиторий. HUD Flutter расположен поверх сцены.
- `content/game-canon.json`, `docs/GAME_CONCEPT.md` — текущий продуктовый канон; `app/lib/content.dart` — встроенные цели, покупки и задания; `app/lib/game.dart` — финансовые правила.
- `docs/`, `references/official/` — правила игры, источники и официальное ТЗ/Q&A; `outputs/` — артефакты сборки и прежние материалы; `work/` — промежуточные данные, не для передачи экспертам.

Для локального запуска перейдите из корня репозитория в `app/` и выполните `flutter pub get`, `flutter analyze`, `flutter test`. Для release APK нужны Android SDK, JDK и личная конфигурация подписи; последовательность и границы воспроизводимости — в [INSTALL.md](INSTALL.md). Без подписи владельца нельзя побайтово воспроизвести подписанный файл `-g`.

Для 0.5.5 `flutter analyze` чист и **5 целевых тестов помощника прошли**. Полный предыдущий прогон 0.5.4 сообщил 243 успешных теста и 1 пропущенный. Android x86-эмулятор подтвердил открытие помощника, ввод с клавиатурой и вывод ответа; это не заменяет запуск arm64 APK на физическом устройстве. Образовательный эффект у детей не измерялся.

## Что не выдавать за актуальную проверку

- `outputs/INSTALL.md` описывает версию 0.3.0, Android 7 и прежний набор героев. Используйте [новую инструкцию](INSTALL.md).
- `outputs/docs/kopilych-documentation-0.4.0.pdf` и `outputs/delivery-2026-09-27/kopilych-manual-v4.pdf` — исторические документы; последний прямо сообщает, что release APK тогда ещё не был готов. Для §5 нужен обновлённый отдельный DOCX/PDF с результатами устройства и реестром прав.
- Прежние технические презентации описывают старые сборки. Для поля сдачи используйте только [презентацию команды PPTX](studio37-lct2026-team-presentation.pptx); актуальные изменения APK описаны в [обновлении 0.5.5](RELEASE-0.5.5.md).
- `outputs/demo-video.mp4` длится 174,69 с, но кадры показывают интерфейс 0.4.0 с 2D-комнатой и «лесовичком». Это **не резервная запись текущего APK**.

Требования взяты из [официального ТЗ, §4, §5, §7.1](../../references/official/lct-2026-city-6-technical-brief.pdf) и [Q&A](../../references/official/lct-2026-city-6-qa.pdf). Для промежуточной сдачи Q&A допускает обычную сборку; текущий `-g` подписан, однако испытание на физическом телефоне остаётся открытым.
