1. Скопируйте APK на телефон и откройте файл в системном установщике. При необходимости разрешите установку из выбранного файлового приложения.

3. Если устройство подключено по USB и доступен `adb`, можно выполнить `adb install -r <путь-к-apk>`. Если уже установлен APK с другой подписью, Android отклонит обновление; сохраните нужные данные перед удалением старой версии.

## Локальный запуск исходников

Нужны Flutter SDK, Android SDK, JDK и доступ к зависимостям из `app/pubspec.yaml`. Проверено с Flutter 3.35.7/Dart 3.9.2. Локальные кэши и ключи подписи в репозиторий не входят.

Сначала скачайте APK по ссылке выше. Из корня репозитория восстановите бинарные мобильные ресурсы, исключённые из Git (скрипт проверит SHA-256 и все пути из `pubspec.yaml`):

```powershell
python tools/restore_assets_from_apk.py C:\path\to\kopilych-0.5.2-arm64-release-20260929-d.apk
```

Затем из корня проекта:

```powershell
Set-Location app
flutter pub get
flutter analyze
flutter test
flutter run
```

Команда `flutter run` требует подключённое совместимое Android-устройство или эмулятор. Сборка release для arm64:

```powershell
flutter build apk --release --target-platform android-arm64 --build-name 0.5.2 --build-number 2009
```

Подписанная release-сборка требует локальный `app/android/key.properties` и ключ владельца, которые не распространяются вместе с исходниками. Для независимой проверки кода можно собрать debug APK без этих секретов. Сборка из исходников без того же ключа не будет побайтово идентична переданному `-d`.
